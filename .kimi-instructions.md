# Kimi Fix Instructions

## When CodeRabbit Flags Something:

### "Unused enum members"
1. Check if enum is used in `_generate()` or `_execute()` methods
2. If NOT used anywhere → remove from enum definition
3. If SHOULD be used but missing implementation → add the implementation
4. Run tests after change

### "Unrecognized properties in .coderabbit.yaml"
1. Remove the invalid properties
2. Validate YAML syntax
3. No tests needed (config only)

## When Gemini Flags Something:

### Logic errors
1. Fix the logic error
2. Add or update unit tests to cover the fix
3. Run full test suite

### Performance issues
1. Implement optimization
2. Benchmark if possible
3. Ensure no functionality regression

## Branch Safety:
- NEVER push directly to `main`
- Always work on PR branches
- Verify `git branch --show-current` != "main" before push
